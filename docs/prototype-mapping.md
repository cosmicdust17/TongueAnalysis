# 11张原型对应关系

保留浅绿背景、深绿操作色、白色圆角卡片、叶片装饰与角色导航。顶部使用微信原生导航栏及系统胶囊，不重复绘制截图中的手机时间、信号等系统内容。

| 原型 | 实现页面 | 行为 |
|---|---|---|
| 用户开始界面 | pages/analysis/index.vue | 图片、症状、持续时间与分析提交 |
| 生成报告界面 | pages/analysis/result.vue | 排队/处理/失败/完成及报告入口 |
| 查看报告界面 | pages/report/index.vue | 卡片报告、PDF导出、知识依据底部弹层 |
| 历史记录 | subpackages/user/history.vue | 从我的进入，查询与分页，不单列底部导航 |
| 用户端我的界面 | pages/mine/index.vue（user角色） | 历史、个人信息、帮助、登录安全 |
| 知识库管理界面 | subpackages/knowledge-admin/library.vue | 条目、来源、分类、审核发布 |
| 知识管理员图谱总览界面 | subpackages/knowledge-admin/graph.vue | 实体关系图、搜索、展开、编辑与来源 |
| 知识库管理员端我的界面 | pages/mine/index.vue（knowledge_admin角色） | 资料、本人操作、登录安全、帮助与退出 |
| 运行概览界面 | subpackages/ops-admin/overview.vue | 实际探测、分析数量、告警、用户管理 |
| 日志界面 | subpackages/ops-admin/logs.vue | 日志搜索、分类、北京时间日期筛选、告警入口 |
| 运维管理员端我的界面 | pages/mine/index.vue（ops_admin角色） | 账号、本人操作、登录安全、帮助与退出 |

补充页面为登录、资料编辑、操作记录、密码修改、帮助、实体编辑、关系管理/编辑、来源列表/编辑、审核列表、用户管理、告警和服务明细。

三个角色使用自定义底部导航，历史记录始终位于“我的”。知识管理和运维管理无角色与权限页面；权限由后端固定角色检查实现。

图谱页当前围绕选定实体展示最多6个相关实体和2个来源。点击实体继续加载其一跳邻居，支持多层探索；后台检索独立使用最多两跳的证据检索。图谱概览接口最多返回80个实体，界面会提示截断，适合课程项目规模。
