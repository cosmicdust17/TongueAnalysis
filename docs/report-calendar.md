# 分析记录月历接口交接

两条查询复用现有路径。月历接口补充 `counts`，月历和当日列表统一改为按舌照上传日筛选。报告详情继续使用原路径和报告 ID。

## 鉴权与日期

三个接口均发送 `Authorization: Bearer <系统 JWT>`，需要普通用户角色。服务端按会话确定用户。返回 `401` 表示登录失效，`403` 表示角色无权限，`422` 表示查询参数无效。访问不存在或非本人的报告详情返回 `404`。

统一按北京时间（UTC+8，`Asia/Shanghai`）划分自然日，以所属舌照的上传时间 `StoredFile.created_at` 为准。上传后跨午夜或跨月才生成报告，仍计入上传那天。参与统计的记录须有已完成的任务，并关联同一用户上传的图片。统计单位是报告份数，同一舌照若对应两份报告，计两份。原「全部记录」使用不带 `date` 的历史接口，可继续查看其中已有的纯文本记录。

## 1. 查某月有报告的日期及份数

**`GET /api/v1/reports/calendar?month=2026-11`**

`month` 必填，格式 `YYYY-MM`。`dates` 是按日期升序排列的非空日期，保留原响应字段。`counts` 是新增的日期到报告份数映射。无记录的日期可用 `counts[date] ?? 0` 读取。

**HTTP 200 响应示例**

```json
{
  "month": "2026-11",
  "dates": ["2026-11-01", "2026-11-24"],
  "counts": {"2026-11-01": 2, "2026-11-24": 1}
}
```

**空月的 HTTP 200 响应**

```json
{"month":"2026-11","dates":[],"counts":{}}
```

## 2. 查所选日期的报告列表

**`GET /api/v1/reports?date=2026-11-01&page=1&page_size=20`**

`date` 采用 `YYYY-MM-DD`。省略 `date` 时为原有完整历史。`page` 默认 1，`page_size` 默认 20，最大 100。可选 `q` 沿用标题和症状搜索。月历计数与当日列表总数核对时，请使用无 `q` 的当日查询。

返回原历史响应结构，报告按生成时间降序，`items[].id` 为报告 ID。以下示例中 `content` 以空对象简写，实际返回已保存的报告内容。`created_at` 仍表示报告生成时间并带 UTC 偏移，日历归属使用上传日。

```json
{
  "items": [
    {"id":"report-b","title":"舌象综合分析报告","analysis_id":"analysis-b","image_id":"photo-b","is_demo":false,"content":{},"created_at":"2026-11-01T16:10:00+00:00"},
    {"id":"report-a","title":"舌象综合分析报告","analysis_id":"analysis-a","image_id":"photo-a","is_demo":false,"content":{},"created_at":"2026-10-31T17:00:00+00:00"}
  ],
  "total": 2,
  "page": 1,
  "page_size": 20
}
```

**当天无报告或只有纯文本记录时的 HTTP 200 响应**

```json
{"items":[],"total":0,"page":1,"page_size":20}
```

## 3. 打开报告详情

**`GET /api/v1/reports/{rid}`**，`rid` 取 `items[].id`。无查询参数。成功返回与当日列表单个 `item` 同结构的完整报告对象。前端可继续用现有详情页和路由参数。

## 前端调用顺序

1. **打开月历**。用北京时间当前月构造 `month`，调用月历接口。以 `dates` 标记日期，从 `counts` 取份数。
2. **切换月份**。用新 `month` 重查，替换上月标记。
3. **点击日期**。用日历选中的日期字符串调用当日列表。展示全部报告，`total` 超过当前已加载数量时继续分页。空列表显示当天无舌照报告。
4. **打开报告**。将选中的报告 `id` 交给原详情页。返回「全部记录」时调用不带 `date` 的历史接口。

小程序现有请求工具会自动拼接 `/api/v1`。若使用该工具，传入的路径从 `/reports` 开始。
